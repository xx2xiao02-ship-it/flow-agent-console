# 0.2.65 账号自动修复

两个目标账号原先保存了会话，却没有专用浏览器关联。旧后台检测遇到缺失关联就跳过，页面把会话读取失败笼统显示为需要登录。

现在先按已保存且可核对的邮箱恢复唯一匹配的专用资料；没有匹配时建立独立资料，仅首次导入该账号已保存的 Google 会话。不借用其他账号资料，不复制日常 Chrome 数据库。随后无头核对真实邮箱和积分，邮箱不一致不得写回会话。

仅网页明确要求登录或人工验证且无头浏览器关闭后，才显示该账号专用窗口。完成后同步关闭；等待超时也清理，保留具体失败原因。后台对同一份会话只自动修复一次，避免持续弹窗。

检查模式禁止生成请求。本次不测试生图或视频。

实测还发现：失效会话跳转 Flow 介绍页；另一账号没有项目编号。身份准备现在可从首页进入，自动点击介绍页的正式进入按钮，不要求已有项目；生成仍要求有效项目。只读浏览器已确认 Betters Monclova 在 Google 登录页显示“已退出账号”，需要本人登录。

本地回归：原64项通过；入口修改后无头检查10项再次通过，账号修复6项通过（包含新增的无项目身份检查与生成限制测试）。真实账号和安装验证以本次发布的 verification.json 及修复记录为准，不将离线测试等同于账号登录成功。
