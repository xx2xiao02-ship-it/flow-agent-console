# 0.2.60 启动检查

- 每次进程启动先检查8项本地运行条件，再扫描普通Chrome显示资料，逐账号重新读取身份和积分，核验专用浏览器目录关联。
- 检查结束前不启动任务工作线程，API生成入口返回503；主界面不挂载，只显示启动进度与详情。
- 进度按已完成项/本轮总项计算，不使用定时模拟进度。账号读取每个最多60秒；需要修复失效会话时，无头检查最多150秒并沿用退出清理。
- 单个账号失败记为待处理，不阻止其他账号在本轮检查结束后使用；严重本地故障阻止启动。
- 自动检测不弹出人工登录窗口；用户在账号管理点击“打开Flow”仍显示窗口。
- 普通Chrome扫描只读显示资料，不复制登录数据库，不猜测账号绑定，不自动新增账号。
- 本机扫描结果默认折叠；后台监控将浏览器关联缺失列为待处理，不能仅凭积分读取成功显示为正常。
- 启动检查不证明官方生成一定成功，也不提交收费测试。

验证范围：启动阻断、异常汇总、监控回归、真实Chromium中本地隔离页面的进度/键盘锁定/解锁。正式安装后的账号核验需要单独记录，不以隔离测试代替。
