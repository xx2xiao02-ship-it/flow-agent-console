# Flow 接入教程｜Windows 小白照着做

这份说明教你：让 Codex 在其他项目中使用你电脑上的 Flow，查询账号和积分，并在你同意后生成图片、视频。

**先查再生成。第一次接入全程不要生成，不消耗 Flow 生成积分。AI 聊天本身仍按你使用的 AI 服务计费。**

## 一、先看你属于哪种情况

- **就是现在这台电脑、现在这个 Windows 用户使用 Codex**：连接和 Skill 已经配置过，直接看第二节，不必重复安装。
- **换了电脑或 Windows 用户，Flow 和 Codex 装在同一台电脑**：看第三节，首次设置一次即可。
- **另一台电脑调用这台电脑的 Flow**：先看第七节。它与本机接入不同，不要直接照抄本机地址。
- **使用其他 AI 软件**：先确认软件支持 MCP；Skill 也需要软件支持。不能保证所有 AI 软件都能直接导入同一种配置。

只记住三个名字：**Flow 客户端**负责生成；**MCP**是 AI 连接 Flow 的工具入口；**Skill**是告诉 AI 如何正确使用 Flow 的操作说明。你不需要学习协议或编程。

## 二、这台电脑现在怎么用（最快的方法）

### 第 1 步：打开 Flow

双击桌面的 Flow 客户端。进入“账号管理”，能看到自己的账号就可以继续。

关闭窗口后如果程序仍在托盘运行，也能接入；右下角托盘选择“退出”后，AI 就无法连接了。

### 第 2 步：在 Codex 新建一个会话

打开你想工作的项目，再新建会话。不要继续使用配置之前一直没关闭的旧会话。如果新会话仍看不到工具，保存工作后彻底退出并重新打开 Codex。

### 第 3 步：把下面这段话发给 AI

```text
请使用 flow-generate Skill 和 flow-console MCP，只查询 Flow 当前支持的能力、账号名称、缓存积分和最近任务。
不要生成图片或视频，不要上传文件，不要刷新或打开账号浏览器，不要消耗 Flow 积分。
请实际调用工具，不要凭记忆回答。如果工具没加载，请告诉我缺少什么。
```

**成功时看到什么：** AI 实际调用 Flow 查询工具，返回本机账号、缓存积分和任务。账号数、积分会变化，不必与别人截图相同。只看到“我可以调用”不算接通。

**失败时先做什么：** 确认 Flow 没退出，再重新打开 Codex 并新建会话。仍失败看第六节。

## 三、新电脑首次接入 Codex（Flow 和 Codex 在同一台电脑）

### 第 1 步：安装并启动 Flow

运行 Flow 安装包，按安装向导完成。使用提供内置 MCP 的 0.2.45 或更新客户端。本机安装版不需要额外安装 Python，也不用给浏览器装插件来完成 MCP 接入。

打开 Flow →“接口接入”→ 找到“AI 接入 · MCP + Skill”。

### 第 2 步：拿到说明和接入包

在这一栏：

- 点“复制接入说明”：可以粘贴给帮你设置的 AI。
- 点“下载接入说明”：保存这份教程，通常到 Windows“下载”文件夹。
- 点“下载 MCP + Skill 接入包”：下载后右键 ZIP →“全部解压”。记住解压位置。
- 点“复制 MCP 配置”：得到当前电脑的程序路径。它是给支持 JSON 配置的软件用的，**不能整段直接粘贴到 Codex 的 config.toml**。

### 第 3 步：推荐让 Codex 帮你配置

在 Codex 发下面这段话，然后把“复制 MCP 配置”的内容粘在后面，并告诉它接入包解压到了哪里。

```text
请帮我在本机接入 Flow。我是 Windows 用户，不熟悉命令行。
请根据后附 MCP 配置找到 FlowConsoleMCP.exe，确认文件存在。
先备份当前 Codex 配置，再添加或更新 flow-console 连接，不覆盖其他服务和配置。
Codex 使用 TOML；请将后附通用 JSON 正确转换，保留 FLOW_MCP_READ_ONLY="1"。
接入包已解压到：<这里改成我的实际目录>。
请找到包里的 skills/flow-generate 文件夹，将整个文件夹安装到当前 Windows 用户的 Codex skills 目录；已存在时先比较，不直接覆盖我的改动。
仅做工具发现、能力、账号和任务查询，禁止生成、上传或收费测试。
完成后告诉我是否需要重启 Codex，以及下一步点击哪里。
```

把 `<这里改成我的实际目录>` 换成真实解压目录，例如 `C:\Users\你的用户名\Downloads\Flow-MCP-Skill`。这只是让 AI 执行本机配置，若出现文件修改权限提示，先确认目标确实是 Codex 配置和 Flow Skill。

### 第 4 步：重新打开 Codex，按第二节查询

一个 Windows 用户通常配置一次即可，不用每个项目重复配置，也不用每个项目再启动一套 Flow。

### 如果你想自己配置（可跳过）

1. 在文件资源管理器地址栏输入 `%USERPROFILE%\.codex`，回车。
2. 找到 `config.toml`，先复制一份备份，再用记事本打开。没有文件时可新建，但要确认不是 `config.toml.txt`。
3. 如果已经有 `[mcp_servers.flow-console]`，修改现有这一段，不要添加同名重复段。
4. 在文件末尾添加以下内容。**示例安装位置是 D 盘；请按 Flow 页面“复制 MCP 配置”里的 command 改成你自己的实际路径。**

```toml
[mcp_servers.flow-console]
command = 'D:\FlowAgentConsole\FlowConsoleMCP.exe'
args = []

[mcp_servers.flow-console.env]
FLOW_MCP_URL = "http://127.0.0.1:8001"
FLOW_MCP_READ_ONLY = "1"
```

5. 保存文件，关闭记事本。不要删除文件中其他配置。
6. 在解压后的接入包中找到 `skills\flow-generate`。复制**整个 flow-generate 文件夹**到 `%USERPROFILE%\.codex\skills`；不存在 skills 文件夹就新建。已有同名文件夹时先备份比较。
7. 检查最终路径是 `%USERPROFILE%\.codex\skills\flow-generate\SKILL.md`，不要套成两层 flow-generate。
8. 重启 Codex，新建会话，发第二节的只读查询指令。

说明：`127.0.0.1` 表示“这台电脑自己”。`FlowConsoleMCP.exe` 由 AI 自动启动，不需要你双击；单独双击它可能出现等待输入的命令窗口，这是工具入口，不是管理界面。

## 四、查询接通后，怎么开启生成

**当前只读设置下，AI 不能生成，单说“允许生成”也不会解除这个开关。**

确实需要生成时，在 Codex 发：

```text
我现在要启用 Flow 生成能力。请只把 flow-console 连接中的 FLOW_MCP_READ_ONLY 从 "1" 改为 "0"，保留其他配置，不要提交任何生成任务。
请告诉我重启后如何使用；每次真实生成仍按我的数量和积分授权执行，不自动重试。
```

保存工作，重启 Codex、新建会话后，才提出真实生成需求。例如：

```text
请使用 flow-generate，为我生成一张坐在窗边的猫的图片，比例1:1，使用2.1模型。
允许这一次消耗 Flow 积分，只提交一次，不连续重试。
请跟踪原任务到结束，成功后下载到我指定的文件夹；失败请说明原因，不重新提交。
下载目录：<填写实际存在的本地文件夹>。
```

视频也要写清模型、时长、画质、比例和数量，例如“Veo 3.1 Fast、8秒、720p、16:9、1条”。AI 先查询当前支持能力和账号，再按你的授权执行；不是所有账号都支持全部模型。

参考图需告诉 AI 文件位置并确认你有权使用。生成可能需要登录或本人验证，按提示处理；不支持自动绕过验证。

**提交成功不等于生成成功。** “排队中/运行中”还要等；只有任务成功且能下载结果才算出图或出视频。失败或结果不确定时先查原任务，不要反复点生成，避免重复扣积分。

## 五、客户端这几个按钮到底有什么区别

| 按钮 | 什么时候用 | 点击后做什么 |
|---|---|---|
| 复制 MCP 配置 | 给 AI 或其他支持 MCP 的软件设置连接 | 粘贴给 AI；Codex 需转换为 TOML，不能直接覆盖配置文件 |
| 复制接入说明 | 请 AI 帮忙或给别人看教程 | 在聊天框 Ctrl+V 粘贴 |
| 下载接入说明 | 留一份离线教程 | 去“下载”文件夹找 .md 文件，可右键用记事本打开 |
| 下载 MCP + Skill 接入包 | 新用户安装 Skill，或技术人员使用源码版 | ZIP 全部解压，安装版用户只需其中的 skills/flow-generate |

ZIP 接入包不是 Flow 安装程序。没有 Flow 客户端的电脑，先安装客户端；同机安装版不用执行 ZIP 中的 Python 安装步骤。

## 六、常见问题：只按你遇到的这一行处理

| 看到什么 | 先怎么处理 | 成功标准 |
|---|---|---|
| AI 说没有 flow-console 工具 | 保存工作、退出并重开 Codex、新建会话；仍没有就把错误发给 AI 检查配置 | 实际调用查询工具成功 |
| 工具能用，但没有 flow-generate Skill | 检查第三节的 SKILL.md 路径，重启 Codex | AI 能读取并使用该 Skill |
| 连接失败 / Connection refused（连接被拒绝） | 启动 Flow；在浏览器打开 http://127.0.0.1:8001/console/ | 能显示 Flow 管理界面，再查询 |
| 找不到文件 / ENOENT | 检查 MCP 配置的 command，确认安装目录内有 FlowConsoleMCP.exe | 路径真实存在；不要指向安装包或主客户端 EXE |
| 配置解析失败 / 重复键 | 恢复备份后请 AI 检查同名配置；不要把 JSON 直接粘进 TOML | Codex 正常启动并加载连接 |
| Read-only / 只读模式 | 仅查询时这是正常保护；需要生成看第四节 | 查询可用；明确开启后才允许提交 |
| 未读取积分 / 需要登录 | 去 Flow“账号管理”手动打开对应账号完成登录或验证，再检测 | 对应账号身份与积分同步；不要靠生成来测试 |
| 已排队但没下载 | 让 AI 查询原任务 ID，不重新生成 | 原任务成功，有结果文件并下载到指定目录 |

排错时可以发错误文字、任务 ID、截图。不要发送 Cookie、Token、Google 会话文件或完整 API 密钥。

## 七、其他电脑通过局域网接入（首次建议让 AI 协助）

这不是复制本机配置就能用：另一台电脑的 `127.0.0.1` 指向它自己，不是运行 Flow 的电脑。

1. 在运行 Flow 的主机打开“接口接入”→“同局域网”。确认带密钥 API 已启用；若显示“未启用”，先让维护人员按客户端启动说明启用。仅设置密钥不等于已开启服务。
2. 记录页面显示的真实局域网 API 地址。Flow 主机要保持运行，两台电脑需能互相访问；不要为了接入把管理后台或 Google 会话开放到公网。
3. 在调用方电脑安装 MCP 适配器并配置 Skill。ZIP 中带 Python 源码，属于进阶方式；请把包和本节交给 AI 配置，不必新手手敲安装命令。
4. 告诉 AI：服务名 flow-console；FLOW_MCP_URL 用主机页面显示的地址；FLOW_MCP_READ_ONLY 设为1；FLOW_MCP_API_KEY 在本机安全配置，不把完整密钥发聊天或提交 Git。程序路径使用调用方本机实际安装的适配器路径，不能照抄主机磁盘路径。
5. 先在调用方新建会话，执行第二节的只读查询。读到 Flow 主机的账号和任务才算接通。局域网接入需在你的实际网络另行验证，本机接通不代表局域网已通过。

进阶源码安装（仅已安装 Python 的维护人员使用）：解压 ZIP，在包含 backend 文件夹的目录打开 PowerShell，依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\backend
```

MCP 程序填写解压目录下 `.venv\Scripts\flow-console-mcp.exe` 的完整路径，参数留空。上传的素材路径、下载位置属于调用方电脑；账号和生成浏览器仍在 Flow 主机。

## 八、给维护人员的补充（普通用户可以不看）

- 工具：flow_capabilities（能力）、flow_accounts（账号缓存）、flow_jobs（最近任务）、flow_get_job（原任务状态）、flow_generate_image（图片）、flow_generate_video（视频）、flow_upload_reference（素材上传）、flow_download_result（结果下载）。
- 只读模式会拦截生成、上传和下载写入；读取账号与任务不提交生成，也不主动刷新 Google 积分。
- 生成还需单次费用确认 acknowledge_possible_charge=true；适配器固定关闭自动重试，失败先查原任务，不自动换号重提。
- 旧 CLI、REST API、原 MCP 入口保留。这里使用的是连接管理后台队列的 flow-console。
- 安装版由 AI 启动同目录 FlowConsoleMCP.exe；源码版使用 Python 运行 flow-agent/console_mcp_entry.py。
- 浏览器策略由后台决定；任务结束不自动证明浏览器已关闭，需看任务记录中的实际关闭结果。
- 接入查询通过不等于收费生成已验证；本教程更新不执行真实生成。

Codex 配置方式参考：[OpenAI 官方 MCP 说明](https://developers.openai.com/codex/mcp)。
