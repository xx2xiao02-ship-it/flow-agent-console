# 0.2.68 任务工作日志

- 任务管理提供“查看日志”和“导出诊断 ZIP”。运行中可刷新。
- 本地保存位置：用户数据目录 `flow-agent/data/work-logs/<任务编号>/`。
- 记录版本、调用入口（客户端/API/MCP；仅诊断标签，不作为鉴权）、参数白名单、调度策略、账号编号、执行阶段、提交次数、脱敏响应分类、结果编号、下载校验和浏览器关闭状态。
- 日志逐事件追加并刷新；单个日志超过1MiB时保留最后500行，再追加新事件。不会改动历史任务或素材。
- 不保存提示词、邮箱、Cookie、Token、原始响应、异常原文、完整路径或堆栈中的源代码。异常只保留类型和文件名/行号/函数位置。
- 失败截图仅截取精确匹配的固定错误提示区域；没有可安全截取的区域时明确记录省略原因。不会截取整个账号或登录页面。
- 历史任务仅显示原有执行摘要，标记为历史摘要，不能补回当时未记录的事件。
- 日志、截图不会触发重试，不改变结果不明任务的保护策略。
- 验证使用离线夹具与本地测试网页，无Google生成调用。旧任务965c699c仍待核对；日志功能不能反向恢复丢失的响应。
