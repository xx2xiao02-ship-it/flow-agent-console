# 0.2.67 同邮箱账号统一

根因：浏览器同步可能产生新的会话文件编号，旧逻辑按文件逐条展示、汇总余额、准备浏览器，同一邮箱会被计作多个账号。

现在按当前会话摘要一致且已核验的邮箱建立逻辑别名；身份不符、邮箱未知或摘要变化的记录不擅自合并。优先保留已有正确专用浏览器关联的账号为主记录。列表、后台监控和积分总量只计算主记录，账号准备和新任务复用主记录；原始会话文件、原任务编号和历史查询保持不变。

同步入口后续识别出相同邮箱的新会话时自动归入已有账号，不新增可调度账号或重复积分。底层会话文件保留以便原任务查询；本次没有删除历史数据，也没有通过真实生成验收。

回归涵盖：去重积分、关联复用、同邮箱再次同步、不同邮箱隔离、身份异常拒绝合并、历史会话字节不变、后台监控和调度限制。
